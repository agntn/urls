Every source answers the same call, `discover(domain, options)`, and returns the same record. What differs is where it gets its URLs, whether it knows when it saw them, and how much it's willing to hand over in one go.

The archives with a CDX index (Wayback, Arquivo.pt, Vefsafn, Common Crawl) know capture dates, so `from` and `to` work on them. The security indexes (AlienVault OTX, URLScan, VirusTotal) know URLs people and scanners ran into, sometimes ones no archive bothered to keep.

::provider-roster
::

## Which one first?

For breadth on an old domain, Wayback. For what's been poked at recently, URLScan and AlienVault OTX. Not sure? `provider: "all"` asks everyone and shows who answered, which beats guessing.
